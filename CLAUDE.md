# Project scope

- Project scope is provide a barber web app where a barber can handle is shop;
- The objective is create a barber web app where an external user can login and can reserver a session by is barber;
- The manager can manage serveral barber, can see each booking of them and can manage also the warehouse. The manager can add also users and create account for barber and users;
- Each barber has a different dashboard page where it can see his own booking;
- The manager has access to a dashboard where he can view all the statistics of his shop / barbershop;
- The code is written in sveltejs (https://svelte.dev/docs/kit/project-types) used with node server and uses typescript. Be sure to use the best convention for developing;
- You must use npm;
- For FE component is very recommended to use bootstrap 5.3 (https://getbootstrap.com/docs/5.3/getting-started/introduction/). 
- This is a demo, the objective is have as soon as possible the project ready in order to show to the client.
- During implementation be sure to use all standard for this framework, DO NOT USE jQuery that is not supported (for example).
- Be sure to use ENV variable when you can. No hardcoded variables when it's necessary
- Be sure to use the best practice for Docker. I want to handle deployment using CI github pipeline
